Header shims for compiling Dawn's D3D12 backend with the Cosmopolitan toolchain (GCC, LP64) — see ../d3d12_spike.py.

* Windows API headers come from Wine (`libwine-dev`, `setup-wine-headers.sh`): they are LP64-safe (mingw's assume LLP64) and give COM methods `__stdcall`, which is ms_abi on GCC.
* `pre.h` is force-included first: it parses every C++ library header the backend uses *before* the translation unit pretends to be Windows, so libc++ keeps its POSIX paths.
* `sal_shim.h`: SAL annotations as empty macros, `IID_PPV_ARGS`.
* `winapifamily.h`: all partitions enabled (DirectX-Headers test them).
* `dxcapi.h`: generated by `../make_dxcapi_shim.py` from DXC's header (replaces its WinAdapter, which clashes with Wine's types).
* `wrl.h`, `wrl/client.h`, `Ole*.h`, `OAIdl.h`, `OCIdl.h`, `DXProgrammableCapture.h`: minimal stand-ins for headers that only exist in the Windows SDK.
